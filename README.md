# Math Simulations Portfolio

Welcome to my applied mathematics portfolio. I build computer simulations to solve probabilistic and financial problems.

## Project 1: Probability Simulation (10,000 Dice Rolls)
- **Concept:** Testing theoretical probability using computer computation.
- **Language:** Python
- **What it does:** Simulates rolling a 6-sided die 10,000 times randomly to verify the law of large numbers.


## Project 2: Financial Risk Simulation (Coin Toss Betting)
- **Concept:** Stochastic processing and capital risk management.
- **Language:** Python
- **What it does:** Simulates 50 rounds of a binary betting game to observe volatility, risk of ruin, and balance fluctuations over time.
